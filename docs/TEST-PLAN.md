# Test plan — Claude apps gateway on Microsoft Foundry

Each case belongs to one roadmap packet (`docs/ROADMAP.md`). The expected result comes from the cited
source. The negative check breaks the condition the case depends on and confirms the result changes;
a case whose negative check does not change the result measures nothing and is rewritten.

## Evidence captured per run

- Gateway stderr: audit events are single-line JSON with an `evt` field; operational lines start with `[gateway]` ([logs](https://code.claude.com/docs/en/claude-apps-gateway-deploy#logs)).
- HTTP status and response headers for each `curl.exe` call (`curl.exe`, not the PowerShell `curl` alias, per the [quickstart](https://code.claude.com/docs/en/claude-apps-gateway#quickstart)), and bodies that hold no credential.
- Claude Code debug file from `claude --debug-file ./claude-debug.txt` for sign-in cases ([troubleshooting](https://code.claude.com/docs/en/claude-apps-gateway-deploy#troubleshooting)).
- Raw evidence stays outside git when it holds identities or tokens; the result row records the file name and a redacted excerpt.
- Access, refresh and device codes, client secrets, `addPassword` responses and deployment request bodies are never written to evidence files; results record status codes, audit event names and redacted identities.
